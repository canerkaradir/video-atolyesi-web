# Video Atölyesi — web sürümü

Tarayıcıda çalışan sade video/ses aracı: video birleştir, video kes, biçim değiştir (MP4 → 3GP, videodan MP3…), ses birleştir, ses kes.

Videolar hiçbir sunucuya gönderilmez; tüm işlem tarayıcının içinde (ffmpeg.wasm) yapılır.
Bu depoda yalnızca programın kodu vardır. `main` dalına gönderilen her değişiklik GitHub Pages'e otomatik yayınlanır.
